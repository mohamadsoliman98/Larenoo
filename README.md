# موقع شركة لارينوو والملوك

موقع تعريفي من صفحة واحدة باللغة العربية لشركة لارينوو والملوك: حلاوة لارينوو بالفستق الحلبي، وحلاوة الملوك بالفستق السوداني والسادة، وطحينة السمسم.

- مبني بـ HTML و CSS و JavaScript فقط، دون أطر عمل أو مكتبات خارجية.
- لا يحتاج خطوة بناء: تُنشر الملفات كما هي على Cloudflare Pages.
- الخطوط والصور كلها مستضافة داخل المشروع، ولا يُحمَّل أي ملف من موقع آخر.
- يعمل المحتوى كاملًا حتى لو تعطل JavaScript؛ الحركة والنوافذ تحسينات إضافية.

## هيكل المشروع

```
index.html            الصفحة كاملة: النصوص، المنتجات، النموذج، بيانات محركات البحث
css/style.css         التنسيقات كلها؛ الألوان والخطوط والمسافات في أول الملف (:root)
js/main.js            القائمة، نافذة تفاصيل المنتج، نموذج طلب الجملة، الظهور عند التمرير
assets/images/        الصور بكل مقاساتها
assets/fonts/         خطا El Messiri و IBM Plex Sans Arabic
_headers              إعدادات الأمان والتخزين المؤقت في Cloudflare
favicon.svg           أيقونة المتصفح (ومعها favicon.png و apple-touch-icon.png)
robots.txt            تعليمات محركات البحث
sitemap.xml           خريطة الموقع
tools/                أدوات الصيانة، لا تؤثر على الموقع
.github/workflows/    فحص تلقائي على GitHub عند كل تعديل
```

## الفحص قبل أي نشر

```bash
node tools/check.mjs
```

لا يحتاج أي تثبيت. يتأكد من:

- وجود كل صورة أو خط أو ملف تشير إليه الصفحة.
- تطابق عرض كل صورة مع اسمها ومع ما هو مكتوب في `srcset`.
- تطابق رقم الهاتف والواتساب في كل المواضع.
- صحة بيانات محركات البحث (JSON-LD).
- أن الروابط التي تفتح في نافذة جديدة آمنة.
- عدم وجود أكواد أو تنسيقات داخل الصفحة تمنعها إعدادات الأمان.
- أن رقم نسخة `style.css` و `main.js` محدّث.

ويعرض تحذيرًا عن الملفات غير المستخدمة وعن الصور ذات الأبعاد غير المتوقعة.

إذا عدّلت `css/style.css` أو `js/main.js` شغّل:

```bash
node tools/check.mjs --fix
```

فيتحدّث رقم النسخة في `index.html` تلقائيًا (`style.css?v=...`)، فيحصل الزوار على التعديل فورًا بدل النسخة المحفوظة في متصفحهم.

يعمل الفحص نفسه تلقائيًا على GitHub عند كل Pull Request، ويظهر أحمر إذا وُجد خطأ.

## تعديلات شائعة

### النصوص

كل النصوص في `index.html`، مقسّمة إلى أقسام بمعرّفات واضحة:

| القسم | المعرّف |
|---|---|
| الواجهة الرئيسية | `#home` |
| المنتجات | `#products` |
| قصتنا والحقائق الأربع | `#about` |
| مكوناتنا | `#ingredients` |
| للتجار ونموذج طلب الجملة | `#partners` و `#wholesale` |
| وسائل التواصل | `#contact` |
| التذييل | `<footer>` |

عنوان الصفحة ووصفها في نتائج البحث وعند المشاركة موجودان في أعلى `index.html` داخل `<head>`: `title` و `description` و `og:*` و `twitter:*`.

### منتج جديد أو تعديل منتج

1. **البطاقة** في قسم `#products`: الاسم `product-card__name`، والوصف، والمكونات، والصورة. طريقة الحفظ موجودة في `data-storage` على زر «تفاصيل المنتج». نافذة التفاصيل تقرأ كل ذلك من البطاقة نفسها، فلا تحتاج تعديلًا.
2. **نموذج الجملة**: أضف اسم المنتج إلى قائمة `<option>` بنفس الكتابة حرفيًا، ليعمل زر «اطلب هذا المنتج بالجملة». أداة الفحص تنبهك إن نسيت.
3. **بيانات محركات البحث**: عدّل أو أضف عنصر `Product` في كتلة `application/ld+json` داخل `<head>`.
4. **لون الشريط والنقطة في البطاقة**: أضف في `css/style.css` سطرًا مثل `.product-card--اسم { --label: #0b3720; }` وأضف الصنف نفسه إلى البطاقة.

### رقم الهاتف والواتساب

الرقم الحالي `963952516412` موجود في:

- روابط `wa.me` في الهيدر، وقائمة الجوال، والزر العائم، وبطاقة التواصل، والتذييل.
- روابط `tel:` والرقم المعروض `‎+963 952 516 412` في بطاقة التواصل والتذييل.
- `telephone` في بيانات محركات البحث.
- `WHATSAPP_NUMBER` في `js/main.js`، وهو المستخدم في رسالة نموذج الجملة.

استبدل الرقم بالبحث والاستبدال في `index.html` و `js/main.js`، ثم شغّل الفحص: سيخبرك إن بقي موضع بالرقم القديم.

### روابط التواصل الاجتماعي

روابط إنستغرام وفيسبوك موجودة في بطاقات التواصل، وفي التذييل، وفي `sameAs` ضمن بيانات محركات البحث.

### الألوان والخطوط

القيم كلها في أول `css/style.css` داخل `:root`، وتتغير في الموقع كله من مكان واحد:

| المتغير | الاستخدام |
|---|---|
| `--primary` | الزيتوني: الهيدر، والأزرار، والعناوين |
| `--brand-yellow` | الذهبي: الأزرار البارزة واللمسات |
| `--background` و `--cream` و `--card` | خلفيات الأقسام والبطاقات |
| `--foreground` و `--muted-foreground` | النصوص |
| `--font-display` و `--font-sans` | خط العناوين وخط النصوص |

## الصور

### الصور الحالية ومقاساتها

| الاسم الأساسي | المقاسات | النسبة | مكان الاستخدام |
|---|---|---|---|
| `larino-halva` | 640، 960، 1280، 1600 + `portrait` 600، 900 | 4:3 و 3:4 | الواجهة الرئيسية (الطولية للهاتف) |
| `larino-sesame` و `larino-tahini` و `larino-pistachio` | 640، 960، 1280 | 4:3 | قسم مكوناتنا |
| `larino-tub-larinoo` و `larino-tub-molouk` و `larino-tub-molouk-plain` و `larino-jar-tahini` | 520، 780، 1040 | 4:3 | بطاقات المنتجات ونافذة التفاصيل |
| `og-image.jpg` | 1200 × 630 | — | الصورة التي تظهر عند مشاركة الرابط، وعليها اسم الشركة |
| `favicon.svg` و `favicon.png` و `apple-touch-icon.png` | 64 و 180 | مربعة | أيقونة المتصفح والهاتف (مؤقتة حتى يُعتمد الشعار الرسمي) |

المقاس في آخر الاسم هو العرض بالبكسل، مثل `larino-halva-960w.webp`. يختار المتصفح المقاس المناسب للشاشة تلقائيًا.

### استبدال صورة

1. جهّز **صورة رئيسية** بأعلى جودة متاحة، بالقصّ الذي تريده ومساحة ألوان sRGB:
   - صور المشاهد: 1600 × 1200 على الأقل.
   - صور المنتجات: 1040 × 780 على الأقل.
2. ثبّت الأداة مرة واحدة فقط (تحتاج Node.js 18 أو أحدث):

   ```bash
   cd tools
   npm install
   cd ..
   ```

3. أنشئ كل المقاسات بالأسماء الصحيحة مباشرة داخل `assets/images`:

   ```bash
   node tools/images.mjs scene larino-halva ~/Desktop/halva.jpg --portrait
   node tools/images.mjs scene larino-sesame ~/Desktop/sesame.jpg --widths=640,960,1280
   node tools/images.mjs pack larino-tub-larinoo ~/Desktop/larinoo.png
   ```

   - `--portrait` ينشئ النسخة الطولية للهاتف.
   - `--focus=0.58` يحدد موضع المنتج أفقيًا في النسخة الطولية، من 0 (يسار) إلى 1 (يمين).
   - `--out=folder` يكتب الصور في مجلد آخر لمراجعتها قبل الاستبدال.

4. إن تغيّر محتوى الصورة، حدّث نصها البديل `alt` في `index.html`.
5. شغّل `node tools/check.mjs`، ثم راجع الصفحة وانشر.

بقاء الأسماء كما هي يعني أن الصفحة لا تحتاج أي تعديل. يحفظ متصفح الزائر الصور يومًا واحدًا، فيرى الصورة الجديدة خلال يوم على الأكثر.

**صورة المشاركة:** الأمر `node tools/images.mjs og photo.jpg` ينشئ صورة مشاركة بالمقاس الصحيح من صورة عادية، **دون** اسم الشركة. إن أردت الاسم عليها فجهّزها بتطبيق تصميم بمقاس 1200 × 630 واحفظها باسم `assets/images/og-image.jpg`.

## النشر

1. اعمل على فرع جديد، وافتح Pull Request إلى `main`.
2. انتظر علامة النجاح الخضراء من فحص GitHub.
3. ادمج. ينشر Cloudflare Pages الفرع `main` تلقائيًا.

بعد أي تغيير كبير، تأكد من:

- أن الموقع يفتح على `https://larinoo.com`.
- إعدادات الأمان عبر [securityheaders.com](https://securityheaders.com).
- شكل الرابط عند مشاركته على واتساب.

## الأمان والأداء

- `_headers` يسمح للصفحة بتحميل ملفاتها فقط. إن أضفت لاحقًا خدمة خارجية (إحصاءات زوار، خريطة، خطوط من موقع آخر) أضف نطاقها إلى `Content-Security-Policy`، وإلا فلن تعمل.
- لا تكتب أكوادًا أو تنسيقات مباشرة داخل `index.html` (`<script>` بلا `src`، أو `style="..."`، أو `onclick="..."`)؛ ضعها في `js/main.js` و `css/style.css`. بيانات JSON-LD مستثناة لأنها بيانات لا تُنفَّذ.
- مدد التخزين المؤقت:

  | الملفات | المدة |
  |---|---|
  | الصفحة نفسها | لا تُحفظ |
  | CSS و JS | يوم واحد، ويتجدد فورًا مع رقم النسخة |
  | الصور | يوم واحد |
  | الخطوط | سنة، لأنها لا تتغير |
